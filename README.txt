BONTHEWAD DATTATRI — PORTFOLIO

This is a static portfolio built with plain HTML, CSS and JavaScript.
It does not use an AI website builder, AI-generated profile image, or AI runtime.
The visual layout, CSS illustrations and interactions are implemented directly in the source files.

RUN LOCALLY
1. Extract the ZIP file.
2. Open the folder in VS Code.
3. Open index.html in a browser, or use the VS Code Live Server extension.

BEFORE PUBLISHING
- Replace the BD initials block in index.html with your own professional photo when you can upload it.
- Review every project description and link.
- The contact form uses mailto and opens the visitor's email application. For a server-backed form, connect Formspree or EmailJS and test it.
- Resume PDF is included in assets.
- Publish the folder using GitHub Pages, Netlify or Vercel.

TECHNOLOGY
HTML5, CSS3, JavaScript. Google Fonts and Devicon are loaded from their public CDNs; GitHub contribution chart is loaded from ghchart.rshah.org.
